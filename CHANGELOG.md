# Changelog

## 0.1.0 — unreleased alpha

- Focused README with repair/evaluation diagrams, a separate CLI reference,
  a friend installation checklist and GitHub/GitLab integration guidance.

- Automatic live comparison against upstream documentation corrections, with
  exact-match shortcuts, semantic judging, resumable request budgets and an HTML
  comparison report. No human labels or ratings required for this mode.

- Paired upstream-reference benchmarks with withheld engineer-authored corrections,
  optional PR discussion snapshots, explicit discussion-input experiments, and
  separate provisional/project-reviewed/independently-audited label metrics.

- Python AST indexing, versioned snapshots, and signature/body change comparison.
- Explicit Python-to-Markdown mappings and deterministic Git documentation review.
- Evidence-bound AI proposals, section-scoped edits, missing-evidence routing, and
  stale source/document rejection.
- Controlled draft publication, matching-draft reuse, and human approval workflows.
- Versioned evaluation fixtures, real-PR pilots, resumable request budgets, and
  operational reports. Independent benchmark review remains pending.
- Wheel/source distributions, `docguard --version`, isolated installation checks,
  and a non-root container with an allowlisted build context.
- Offline browser review packets with explicit human labels and repair ratings;
  resumable five-method experiments with shared-candidate semantic validation,
  coverage, decision errors, token accounting, and validator error measurements.
  Semantic validation is experimental and does not gate production publication.

No registry release has been published by this implementation. There is no
automatic merge or general multi-language parser. Independent benchmark labels and
held-out value comparisons are still pending.
